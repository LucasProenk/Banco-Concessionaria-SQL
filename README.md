# 🚗 Banco de Dados - Concessionária (Oracle SQL)

Este projeto contém o esquema de um banco de dados para gerenciamento de veículos, marcas, modelos e clientes de uma concessionária.

## 📊 Estrutura das Tabelas

* **CONCES:** Dados das unidades da concessionária.
* **MARCA / MODELO:** Organização hierárquica dos veículos.
* **VEICULOS:** Registro detalhado (Chassi, Placa, Ano, Cor) e status de venda.
* **CLIENTEC:** Cadastro de clientes (suporta Pessoa Física e Jurídica).
* **CLIENTEVEIC:** Tabela de relacionamento para registrar as vendas (Nota Fiscal e Data).

## 🚀 Como usar
O script foi desenvolvido seguindo o padrão **Oracle SQL**. Pode ser executado em ambientes como Oracle SQL Developer ou Apex.
